# Release Notes

## v2.0.2 (2026-11-02)

Maintenance release focused on compatibility and reliability.

### Highlights

- Added support for Python 3.14 and require Python 3.11 or newer.
- Refreshed core dependencies and development tooling for current Python versions.
- Fixed an issue reading certain Arrow-backed string data with newer pandas versions.
- Improved internal code quality and maintainability without changing the public API.

### Notes for Users

- Python 3.10 is no longer supported.
- Existing configurations and workflows remain compatible.
- No configuration or public API changes are required.
